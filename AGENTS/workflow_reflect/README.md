# Workflow Reflection

This folder stores workflow reflection, scaffold review, upgrade prompts, and
historical workflow evidence. It is for improving how agents work in this repo,
not for quick task commands.

Use `../command.md` for reusable quick commands. Use `../workflow.md` for
durable repo workflow rules.

## Folder Map

- `README.md`: this folder map and usage boundary.
- `ai_workflow_upgrade_2026-07-23.md`: dated reusable prompt for adapting prior
  AI-assisted research workflow lessons into this repo.
- `reference_ai_workflows/`: imported and repo-exported workflow summaries used
  as evidence when reflecting on or upgrading the local workflow.

## Versioning

Keep dated workflow-upgrade prompts instead of overwriting them. For example, a
future `ai_workflow_upgrade_2026-07-24.md` should be added beside the
`2026-07-23` version.

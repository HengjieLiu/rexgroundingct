# Agent Guide Map

This folder is the working guide for coding agents and future maintainers.
Read all files here before making changes.

## Reading Order

1. `workflow.md`: repo workflow, checks, and commit hygiene.
2. `command.md`: reusable quick commands for common user requests.
3. `environment.md`: Docker, submodule, mounts, and setup commands.
4. `data.md`: dataset paths and artifact-handling rules.
5. `experiments.md`: experiment IDs, configs, sync, and result policy.
6. `literature_and_code.md`: key literature and code map.
7. `hardware.md`: known machine, GPU, and storage assumptions.
8. `goals.md`: current research goals and open decisions.

After this folder, read `../docs/ai_workflow.md` and
`../docs/current_status.md` for substantial experiment, submission, or workflow
work.

## Folder Map

- `README.md`: this index and required reading order.
- `workflow.md`: day-to-day engineering rules.
- `command.md`: reusable quick commands such as topic-clustered commit
  preparation.
- `environment.md`: environment and Docker setup notes.
- `data.md`: data location and Git exclusion conventions.
- `experiments.md`: experiment lifecycle and provenance rules.
- `literature_and_code.md`: source material and implementation map.
- `hardware.md`: hardware and runtime capacity assumptions.
- `goals.md`: project goals to refine over time.
- `workflow_reflect/`: workflow reflection, upgrade prompts, and historical
  workflow evidence used when improving agent guidance.

# Submission reviews

Use `comparison.md` for human interpretation; it is intentionally not generated
by refresh. Link every reported result to its submission ID, upload event and
leaderboard evidence. Label any local val200 metrics separately, including the
cohort and selection qualification. Record comparisons within a family for
postprocessing effects and between raw variants for model differences.

Keep dated notes when evidence changes. No measured test result or ranking is
inferred from prediction readiness. Large plots or screenshots stay outside Git.

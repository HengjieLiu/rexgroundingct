# Codex Prompt Archive

This folder stores polished reusable prompts and adapted plans for future Codex
sessions. It is not a raw chat transcript archive.

## What To Save

Save prompts or plans when they are likely to be reused:

- experiment launch planning;
- challenge source refresh;
- submission packaging;
- result synthesis;
- workflow upgrades;
- commit preparation for a multi-file research milestone.

Each archived prompt should include:

- purpose;
- required context files;
- constraints and defaults;
- expected artifacts;
- checks or acceptance criteria.

## What Not To Save

- raw conversations;
- secrets, tokens, private accounts, or identity-breaking metadata;
- large outputs or generated runtime logs;
- one-off prompts that do not encode a reusable workflow.

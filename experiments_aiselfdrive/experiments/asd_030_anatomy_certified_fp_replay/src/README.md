# ASD-030 source contract

Experiment-local modules will implement deterministic component extraction,
physical-space anatomy certification, immutable replay serialization,
tri-state loss masking, matched schedules, paired metrics, and leakage guards.

`known_positive` always overrides a certificate. `unknown` is represented
explicitly and must contribute zero negative loss. Source modules may import
existing repository code read-only but must not modify it.

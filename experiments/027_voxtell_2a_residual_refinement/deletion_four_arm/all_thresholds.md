# All saved deletion thresholds and base controls

All four arms and all evaluated checkpoints (epochs 1, 5, 10, 20), in fixed order. These are the recorded results; no threshold or checkpoint has been selected. Status remains **pending_user_review**.

Removal score > threshold deletes a base-positive voxel after tiled blending. A lower removal threshold permits more deletion. Threshold 1.00 reproduces the base exactly. Base controls instead keep voxels whose original base logit is at least the control threshold; their numeric thresholds have a different meaning.

A = 35 findings; B = 34; full = 69. A is development data, fitted by runs 2–4. B is gradient-held-out for runs 1–3 and fitted by run 4. Inspecting B across thresholds does not create a new independent test set. Run 4 is an in-sample capacity diagnostic.

Dice, voxel precision and recall are means over findings. TP retention and FP removal are pooled voxel ratios relative to the same subset of the cached base. Retention flags count individual findings below 95% / 80%; findings with zero base TP have undefined retention (two across the full cohort). FP removal alone does not measure preserved sensitivity. All CSVs retain unrounded values and all recorded aggregate fields.

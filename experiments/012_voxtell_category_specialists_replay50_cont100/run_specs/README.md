# Exp012 Run Profiles

This directory holds canonical configurations for follow-up runs inside the
Exp012 umbrella. Each profile is snapshotted into its runtime run group before
training begins. The original Run 1 remains defined by the experiment-level
config in `configs/experiments/` and is indexed as `r01_core_replay50`.

`r02_2d_diffuse_replay_ratio.json` defines the queued 2d and diffuse
replay-ratio comparison.
